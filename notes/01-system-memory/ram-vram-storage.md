# RAM、显存、存储与 Swap

## 一句话

程序跑在 RAM/显存里；硬盘放文件；RAM 不够时 OS 用 Swap 把冷页换到硬盘，能救急但很慢。

## 三层

```text
硬盘（存储）  大、慢、便宜  → 模型文件、页面文件
内存（RAM）   中速、有限    → 程序、CPU 推理权重
显存（VRAM）  快、更小      → GPU 推理主战场
```

## Swap / mmap / offload

| 机制 | 作用 |
|------|------|
| **Swap** | RAM 页 ↔ 硬盘，自动、慢 |
| **mmap** | 映射文件到内存，按需读页 |
| **GPU offload** | 权重放 RAM/盘，算时拷进显存，很慢 |

大模型：权重可从硬盘加载，但推理若反复换页会极慢；正常靠 **量化 + 足够显存**。

## 设备对照（约 2025–2026）

| 设备 | 运行内存 |
|------|----------|
| 手机主流 | 8～12 GB |
| 手机旗舰 | 12～16 GB |
| 笔记本主流 | 16 GB |
| 台式主流 | 16～32 GB |
