# Attention 与 Q/K/V

## 一句话

**Q 问「我要什么」，K 答「能否匹配」，V 是「匹配后拿走的内容」**；分数来自点积，权重来自 softmax，输出是对 V 的加权平均。

## 公式

```text
S = Q × K^T / √d
P = softmax(S)
O = P × V
```

## 为何三个矩阵

同一词三种角色，由可学习的 `Wq, Wk, Wv` 投影得到：

| | 直觉 |
|---|------|
| Q | 这个词在找什么信息 |
| K | 这个词如何被匹配（索引） |
| V | 贡献什么内容（正文） |

## 「我吃苹果」例子

苹果的 `Q_苹果` 与 `K_吃` 点积大 → softmax 后「吃」权重大 → 输出多从 `V_吃` 借信息。

分数 **不是人给的**，是 **Embedding + 投影 + 训练** 学出来的。
